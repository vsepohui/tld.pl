# NAME

tld.pl - TLD \*.pl redirector to Metacpan

# SYNOPSIS

    Usage: mantra [--port=80] [--tld=pl]
    
        tld.pl --port 9090 --tld pl.vsepohui.ru
    
    Options:
    
        port - Binding port (default: 80)
        tld  - TLD (default: pl)
